# KuponSocial — тестовый сайт для Card Collector

Простой статический сайт «как соцсеть» (без регистрации, без бэкенда — чистый HTML/CSS) с
лентой из 6 постов. Каждый пост — купон/подарочная карта/карта лояльности/билет с QR-кодом,
как в реальных приложениях-агрегаторах купонов.

**Это не настоящая соцсеть и не настоящие купоны.** Все QR-коды — выдуманные тестовые строки
(`SPT-MBR-…`, `PAT-GFT-…` и т.д.), у них нет реальной ценности и они нигде не активируются.
Сайт сделан только для того, чтобы проверить, находит ли [Card Collector](../card_collector_v2)
купоны/карты с QR-кодами на странице вообще.

## Почему именно эти бренды и коды

Локаль — `it_CH` (итальянский, Швейцария). Бренды (`Splash e Spa Tamaro`, `Pathé Suisse`,
`Blue Cinema`) и тексты категорий (`tessera`, `buono sconto`, `buono regalo`, `biglietto`) —
настоящие записи из `data/merchants.csv` приложения, не выдумка. Перед тем как страница была
собрана, каждая из 6 картинок была прогнана через настоящий `Detector` приложения (тот же код,
что использует сам Card Collector) и подтверждена: код читается, бренд узнаётся, категория
определяется верно. Так что результат на этой странице предсказан заранее, а не угадан.

Разбивка по категориям:
- **membership** (карта лояльности) — `images/splash_membership.png`
- **coupon** (купон) — `images/splash_coupon.png`
- **gift_card** (подарочная карта) — `images/pathe_giftcard.png`, `images/bluecinema_giftcard.png`
- **ticket** (билет) — `images/splash_ticket.png`, `images/pathe_ticket.png`

## Как использовать

1. Опубликуйте этот сайт (например, GitHub Pages — см. ниже).
2. В Card Collector откройте страну `it_CH`, вкладку «Источники».
3. Вставьте ссылку на опубликованный `index.html` (или просто на корень сайта) в поле
   «Ссылка на сайт» → «Проверить и добавить».
4. «Запуск» → «Начать сбор». Ожидаемый результат: обработано 6, принято 6, отклонено 0.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Test site for Card Collector"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git push -u origin main
```

Дальше на GitHub: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)**.
Через минуту-другую сайт будет доступен по адресу
`https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`.
